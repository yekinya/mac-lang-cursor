# LangCursor

macOS 메뉴바에서 설정하는 데스크톱 반려동물입니다. 처음 실행하면 흰 고양이가 커서를 따라다니며, 쉴 때 몸을 단장하고 클릭에 반응합니다. 메뉴의 `동물 선택`에서 강아지나 햄스터로 바꿀 수 있습니다. 세 동물 모두 달리기·앉기·쉬기 동작을 담은 전용 스프라이트 시트를 사용합니다.

| 메뉴 | 동작 |
| --- | --- |
| 따라오기 대기 시간 | 커서가 멈춘 뒤 짧게(0.4초), 중간(1.8초, 기본), 길게(3.5초) 기다렸다가 출발합니다. |
| 쉬는 동작 · 클릭 반응 | 두 기능 모두 기본으로 켜져 있습니다. 쉬는 동안 눈을 깜빡이거나 몸을 단장하며, 강아지는 앉아서 꼬리를 흔듭니다. 클릭 반응을 끄면 동물을 통과해 아래 창을 클릭할 수 있습니다. |
| 배고파지는 시간 | 무작위 모드에서는 식사를 마칠 때마다 10~20분 중 다음 간격을 뽑습니다. 시간이 되면 동물이 밥그릇을 가져옵니다. 그릇을 클릭하면 사료를 먹습니다. |
| 배변 간격 · 파리 표시 | 무작위 모드에서는 배변할 때마다 별도로 10~20분 중 다음 간격을 뽑습니다. 똥은 화면에 최대 5개까지 남습니다. 파리를 별도로 켜면 약 5초 동안 맴돌다 날아갑니다. |
| 똥 남기는 시간 | 똥이 생긴 뒤 5초 또는 30초(기본)에 치우거나, 클릭할 때까지 남깁니다. 개별 클릭과 메뉴에서 모두 치우기도 가능합니다. |
| 입력 언어 배지 | 커서 옆에 현재 입력 언어를 표시합니다. 기본적으로 입력이 멈춘 뒤 5초 후 숨기며, 항상 표시하도록 바꿀 수 있습니다. |
| 메뉴 언어 | 시스템 언어를 따르거나 한국어, 영어, 중국어 간체, 일본어, 스페인어, 프랑스어를 직접 선택합니다. |

배고픔, 배변, 파리, 입력 언어 배지는 새 설치에서 꺼져 있습니다. 배변과 먹이의 기본 활성 모드는 각각 10~20분 무작위이며, 커서 이동으로 타이머가 초기화되지 않습니다. 짧은 고정 간격을 직접 고르면 종전처럼 커서가 멈춘 시간을 사용합니다. 메뉴에서 바꾼 값은 재실행 후에도 유지됩니다. 이전 버전에서 선택한 크기, 배고픔·배변 간격, 배지 항상 표시 설정도 이어집니다.

## 빌드와 실행

macOS 13 이상(Apple Silicon 및 Intel)에서는 [맥 설치본](build/LangCursor-macOS.dmg)을 열고 `LangCursor.app`을 `Applications`에 끌어다 놓은 뒤 실행합니다. 재설치할 때는 메뉴바에서 앱을 먼저 종료하세요.

`build/`의 설치본은 Git에 포함됩니다. 브랜치에 푸시하면 GitHub Actions가 빌드 입력과 설치본의 체크섬을 확인하고, 변경이 있으면 테스트와 빌드를 거쳐 같은 브랜치에 설치본을 커밋합니다.

소스에서 직접 빌드하려면 다음 명령을 실행합니다.

```sh
./scripts/build-app.sh
open dist/LangCursor.app
```

## 권한

타자 감지와 전환 키 즉시 표시에는 **입력 모니터링** 권한이 필요합니다.
시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 LangCursor를 켜 주세요.
권한이 없어도 언어 변경과 마우스 이동에 따른 표시는 동작합니다.

앱은 키 코드만 확인하며, 입력한 내용을 읽거나 저장하지 않습니다.

앱을 ad-hoc 서명하므로 다시 빌드하면 macOS가 다른 앱으로 인식합니다.
재빌드 후 권한이 듣지 않으면 목록에서 LangCursor를 지우고 다시 추가하세요.

## 테스트

Xcode가 있으면 `swift test`로 실행합니다. Command Line Tools만 쓴다면 매크로 경로를 지정합니다.

```sh
swift test -Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing
```

## 스프라이트와 언어팩

각 동물은 `Sources/LangCursor/Resources/`의 1024×1024 투명 PNG 한 장을 씁니다. 행은 오른쪽·위쪽·아래쪽 달리기, 앉기, 대기, 발 핥기, 세수, 기지개 순서이며 왼쪽 달리기는 오른쪽 달리기를 반전합니다. 원본과 생성 프롬프트는 `Artwork/`에 있습니다.

```sh
swift scripts/pack-cat-atlas.swift Dog
swift scripts/verify-cat-atlas.swift Dog
```

인수는 `Cat`(기본), `Dog`, `Hamster` 중 하나입니다. 메뉴 번역은 [MenuLanguages.json](Sources/LangCursor/Resources/MenuLanguages.json)에 한국어 원문을 키로 두고 `en`, `cn`, `ja`, `es`, `fr`에서 찾아 씁니다.
