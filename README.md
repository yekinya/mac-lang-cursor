# LangCursor

마우스 커서 오른쪽에 현재 입력 언어(`한` / `A`)를 반투명 배지로 보여 주는 macOS 메뉴바 앱입니다.

작은 흰색 고양이가 **독립된 투명 창**에서 커서를 따라 달립니다. 일반 앱 창 위에 표시되며, 고양이 그림 영역을 뺀 나머지 클릭은 아래 창으로 통과합니다.

- 마지막 커서 이동 후 1.8초 기다렸다가 일어서기 없이 바로 달립니다. 낮은 가속도와 감속도로 천천히 easing 이동하며, 작은 커서 떨림에는 반응하지 않습니다. 이동 속도는 느린 easing 버전에서 15% 높였습니다.
- 쉬는 동안 숨쉬기·눈 깜빡임·발 핥기·세수·기지개가 이어집니다. 모든 애니메이션을 최초 버전의 0.5배속으로 재생합니다.
- 위·아래·좌·우 달리기와 앉기까지 하나의 **8×8, 64프레임 투명 PNG**를 사용합니다. 왼쪽 달리기와 앉기는 함께 반전하여 방향이 갑자기 바뀌지 않습니다.
- 메뉴바의 `바탕화면 고양이`로 표시를 끄고 켤 수 있고, `고양이 크기`에서 아주 작게/작게/보통을 고릅니다. 모든 크기를 최초 버전보다 20% 줄였으며 기본 창은 51.2pt, 실제 고양이는 약 29–44pt입니다. 설정은 저장됩니다.
- Space 이동, 화면 연결 변경, 잠자기와 깨우기를 처리하며 전체 화면 앱에도 표시합니다.
- 고양이를 클릭하면 커서 쪽을 보고 앞발로 할퀴며 몸을 떱니다. 할퀸 자국 세 줄이 생기고, 머리 위에 흰 테두리 글자로 "하악!"이 한국어·영어·일본어·중국어·독일어·프랑스어·스페인어·러시아어 중 하나로 뜹니다(직전과 같은 말은 연달아 나오지 않음). 앱을 활성화하거나 포커스를 빼앗지 않습니다.
- 마우스가 정해진 시간 동안 가만히 있으면 고양이가 엉덩이 쪽에 똥(💩)을 한 번 쌉니다. 똥마다 웃음·윙크·놀람·졸림·뿌루퉁·메롱·하트 눈·어질어질 중 하나의 표정이 무작위로 붙습니다. 똥 위로는 파리 2~3마리가 제각각 구불구불 날아다니다가, 5초 뒤 화면 쪽으로 다가오듯 커지며 사라집니다. 똥은 커서로 **클릭해야만** 치워지며, 화면에 최대 5개까지 쌓입니다. 메뉴바의 `똥 모두 치우기`로 한 번에 치울 수도 있습니다. 다시 싸려면 마우스를 한 번 움직였다가 또 멈춰야 합니다. 시간은 메뉴바의 `가만히 있으면 똥 싸기`(10초 기본/30초/1분/3분/끄기)에서 고릅니다.
- 마우스를 정해진 시간 동안 움직이지 않으면 배가 고파진 고양이가 화면 가장자리로 가서 빈 밥그릇을 물고 돌아와 내려놓고 기다립니다. 밥그릇을 클릭하면 사료가 쏟아져 그릇이 톡 튀고, 고양이가 약 6초 동안 먹은 뒤 빈 그릇은 사라집니다. 물고 오는 중에 클릭해도 그 자리에 내려놓고 먹습니다. 가장자리로 가는 도중에 마우스를 움직이면 취소되지만, 밥그릇을 문 뒤에는 밥을 줄 때까지 그 자리에서 기다립니다. 시간은 메뉴바의 `배고파지는 시간`(30초/1분 기본/3분/5분/10분/끄기)에서 고릅니다.

- 마우스를 움직이거나 타자를 치는 동안 표시되고, 아무 입력이 없으면 5초 뒤 사라집니다.
- 한영 전환 키를 누르는 즉시 표시합니다. 전환이 씹히면 언어가 그대로이니 바로 알 수 있습니다.
- 메뉴바의 `항상 켜져 있기`를 켜면 사라지지 않습니다.

## 빌드와 실행

macOS 13 이상(Apple Silicon 및 Intel)에서는 [맥 설치본](build/LangCursor-macOS.dmg)을 열고 `LangCursor.app`을 `Applications`에 끌어다 놓은 뒤 실행합니다. 재설치할 때는 메뉴바에서 앱을 먼저 종료하세요.

`build/`의 설치본은 Git에 포함됩니다. 브랜치에 푸시하면 GitHub Actions가 빌드 입력과 설치본의 체크섬을 확인하고, 변경이 있으면 테스트와 빌드를 거쳐 같은 브랜치에 설치본을 커밋합니다.

소스에서 직접 빌드하려면 다음 명령을 실행합니다.

```sh
./scripts/build-app.sh
open dist/LangCursor.app
```

## 권한

타자 감지와 전환 키 즉시 표시에는 **입력 모니터링** 권한이 필요합니다.
시스템 설정 > 개인정보 보호 및 보안 > 입력 모니터링에서 LangCursor를 켜 주세요.
권한이 없어도 언어 변경과 마우스 이동에 따른 표시는 동작합니다.

앱은 키 코드만 확인하며, 입력한 내용을 읽거나 저장하지 않습니다.

앱을 ad-hoc 서명하므로 다시 빌드하면 macOS가 다른 앱으로 인식합니다.
재빌드 후 권한이 듣지 않으면 목록에서 LangCursor를 지우고 다시 추가하세요.

## 테스트

Xcode가 있으면 `swift test`로 실행합니다. Command Line Tools만 쓴다면 매크로 경로를 지정합니다.

```sh
swift test -Xswiftc -plugin-path -Xswiftc /Library/Developer/CommandLineTools/usr/lib/swift/host/plugins/testing
```

## 고양이 스프라이트

실행에 사용하는 유일한 시트는 `Sources/LangCursor/Resources/CatSpriteAtlas.png`입니다. 1024×1024px, 셀 128×128px이며 행 순서는 오른쪽 달리기 / 위쪽 달리기 / 아래쪽 달리기 / 앉기 / 대기 / 발 핥기 / 세수 / 기지개입니다. 출발할 때는 앉기 역재생을 생략하고 바로 달립니다.

Imagegen으로 만든 원본과 생성 프롬프트는 `Artwork/`에 보관합니다. 원본의 투명 여백을 잘라 같은 배율·바닥 기준점으로 다시 배치하려면 `swift scripts/pack-cat-atlas.swift`를 실행합니다. 프레임 누락·가장자리 잘림 검사는 `swift scripts/verify-cat-atlas.swift`로 실행합니다. 빌드 스크립트가 스프라이트 리소스 번들을 앱 안에 함께 복사하므로 빌드 폴더 밖에서도 실행됩니다.
